# Knockout Royale 777

SwiftUI social slots game — **virtual coins only**, offline/local, no IAP, no third-party services.

## Open on Mac

1. Copy `KnockoutRoyale777/` to your Mac.
2. Open `KnockoutRoyale777.xcodeproj` in Xcode 15+.
3. Select your **Team** under Signing & Capabilities.
4. Run on iPhone / Simulator (iOS 17+).

## Bundle

- Display name: `Knockout Royale 777`
- Bundle ID: `com.knockoutroyale.slots777` (change if needed)
- Portrait only
- Category: Games

## App Store notes

- Age rating: **17+** (Simulated Gambling)
- Include in review notes: virtual currency has no real-world value; no cashout; entertainment only
- Add a 1024×1024 App Icon in `Assets.xcassets/AppIcon`
- Screenshots from simulator/device before submit

## Features (v1)

- Home, Arena select, 4 playable arenas, Rewards, Profile, Settings
- Local persistence (UserDefaults)
- Silent (haptics only on wins)
- Daily login, daily chest, missions, achievements
